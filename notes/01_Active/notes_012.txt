2. DETAILED ARCHITECTURAL PROPOSALS
==================================

2.1 Explorer drag-and-drop and shared file import
------------------------------------------------

Use DragAcceptFiles and a pointer-width-correct WNDPROC subclass on the real
Tk Text child of input_box. This limits acceptance to the text surface rather
than the whole window. Discover the Tk child through winfo_children(), avoiding
CustomTkinter's private _textbox attribute. Scrollbars and margins are not drop
targets in this first implementation; a visible Open file action is the fallback.

The native callback copies exactly one Unicode file path into a bounded queue,
calls DragFinish in a finally clause and returns promptly. It performs no Tk
calls, file reads, dialogues or backend operations. Other Windows messages go
to the previous procedure through CallWindowProcW. Use c_ssize_t for LRESULT
and LPARAM, c_size_t for WPARAM and c_void_p for HWND; never default c_int for
pointers. Use SetWindowLongW/GetWindowLongW only for 32-bit Python, where the
Ptr names are C macros rather than guaranteed DLL exports. [S1–S5]

Retain the callback object for as long as native code can call it. Restore the
previous procedure before destruction, but only if this callback is still at
the head of the chain. If another subclass is above it, disable this handler
and keep it pinned until process exit; overwriting the newer subclass is unsafe.
For this one-window application, one small pinned object is a reasonable bounded
trade-off. WM_NCDESTROY marks the native handle invalid and forwards the message.
Do not detach when merely hiding to the system tray. [S3–S6]

The Tk after pump consumes paths and worker results. Only one import worker is
allowed at a time. Capture both an edit revision and request id before reading;
discard a completion if editing, Clear, a translation request or another import
superseded it. Capture state again after a modal replacement question, because
Tk runs a nested event loop while the question is visible. The native queue is
bounded; excess queued drops are ignored while an import is active.

Read .txt/.md as UTF-8 (including BOM) or BOM-marked UTF-16. Reject unknown
encodings rather than silently replacing French accents. Preserve Markdown as
literal source text. Limit raw input to 2 MiB, ZIP expanded size to 8 MiB and
extracted text to the configured input character limit, currently 2,000. Never
truncate silently. Inspect a .docx ZIP before passing its in-memory bytes to
python-docx; no archive member is extracted to disk.

Word scope: body paragraphs and ordinary tables, in document order. The proposed
reader rejects tracked revisions and nested tables to avoid a misleading partial
import. Images, headers, footers, footnotes and text boxes are not reproduced;
the import notice makes body-text-only behaviour explicit. python-docx 1.2's
iter_inner_content provides paragraph/table order; older installations without
that API receive an actionable message. [S7]

WM_DROPFILES is the intended Explorer filesystem path flow, not a universal OLE
drop target: Outlook attachments and virtual/cloud-only items can behave
differently. Same-integrity Explorer/Plume, normal user privileges, the bundled
Tk version and Windows scaling must be tested. Do not relax Windows message
filters or run Plume elevated to work around a drag-and-drop problem.

Performance: O(input bytes + extracted text), one bounded worker, one 75 ms
queue pump, no backend call, no file path persisted. ZIP checks bound the proposed
input, but do not claim to sandbox arbitrary Office documents.

2.2 User presets, persistence and Scriptorium compatibility
---------------------------------------------------------

Current conversation presets already save direction, French address form,
speaker/recipient gender and situation. Add tones to that existing schema.
Existing entries without tones naturally migrate to [] on load. Do not create a
second catalogue or copy WRITING_PRESETS from an unrelated application.

Current issues and severity:
- P1 reliability: Save/Delete mutate config_data before saving; ConfigError is
  swallowed and OSError is not handled (3278–3284, 3290–3298). The UI can claim
  a preset exists when it was not persisted, or lose it from memory on failure.
- P2 usability: names need not be unique but selection/deletion is by name.
  Saving at the 12-entry cap can silently discard the new entry.
- P2 consistency: preset normalisation discards tones (925–936).
- P2 consistency: an already-open Settings dialogue holds a snapshot. Saving it
  after a preset change can overwrite the newer preset list unless refreshed.

Build a candidate config, persist it first using existing save_config(), then
publish it to config_data and refresh the menu. Catch ConfigError and OSError
with a generic, visible message. Never use force=True for normal preset edits.
Use an explicit duplicate-name refusal and an explicit full-list refusal.
An Update action can follow later; do not silently overwrite a namesake.

Keep stable IDs in records. In the minimal phase, the menu remains name-based,
so normalise legacy duplicate display names deterministically to unique names
and reserve the placeholder label. New presets reject duplicate names using
casefold(). Existing IDs are preserved. Display-name repairs become durable
only at the next successful save; loading itself remains read-only.

Use plume_config.json through config_path() for the current application. The
brief explicitly requests scriptorium_config.json: support that exact filename
as an OPTIONAL selected legacy destination, rather than accidentally writing two
authoritative files. Snippet B4 shows a one-line filename switch if that is the
chosen product requirement. It requires a deliberate migration of the existing
Plume file and the credential exclusion in .gitignore; do not just change the
constant and make current settings disappear. Recommended integration retains
plume_config.json and offers an explicit preset-only legacy import/export later.
Do not export backend keys, privacy acknowledgement or autostart settings with
presets. No migration is performed as part of this report.

Mode/Strength/Role are an optional, genuinely new second phase, not fields that

2.3 Three-tone composition and prompt evolution
-----------------------------------------------

No increase to MAX_TONES is needed. The current validator can raise TypeError
for unhashable JSON entries such as a dict/list at line 1135. It stops examining
inputs once three tones are selected; later conflicting inputs are ignored.
The UI resolves by fixed slot order, so a new choice in slot one can lose to an
old choice in slot three, despite the catalogue comment saying new choices win.

Proposed deterministic policy: process only string catalogue values; for each
new valid tone remove its duplicates and incompatible earlier tones, then append
it and retain the most recent three. Idempotence, uniqueness, membership, cap
and absence of all conflict pairs are testable invariants. In the UI, the changed
slot is placed last before normalisation, so the newest user action wins. Saved
order is preserved without pretending it records every historical click.

Retain the existing conflict graph. It is editorial policy rather than a proven
linguistic law. Verify all catalogue sequences of lengths 0–4 exhaustively and
confirm both directions of each conflict pair. Warm/Precise/Courteous is a valid
triple; Terse/Warm/Playful resolves to Warm/Playful. Announce conflict removal in
the advisory label so choices do not appear to vanish silently.

The source remains authoritative. Add explicit preservation of negation,
uncertainty, attribution, quantities, deadlines and obligations. Warm/Reassuring
cannot invent comfort or promises; Courteous cannot add gratitude/apologies;
Playful cannot add jokes. The rule applies to the primary and all five variants.
Prompt guards reduce risk but do not prove semantic fidelity. Existing JSON and
placeholder validators remain mandatory. Do not market deterministic tone
validation as deterministic model behaviour or hallucination prevention.

Calibrate prompt changes separately from UI fixes. Compare baseline and candidate
on fixed bilingual examples (negation, uncertain dates, promises, indirect
requests, slang, gender ambiguity and protected names), across both backends.
Record model/version/settings; human-review meaning retention before adopting
the profile strength options. No calibration API calls were made for this note.

2.4 Export, clipboard and metrics
---------------------------------

A source/translation diff is a textual comparison across languages, not a measure
of edits or translation quality. Label it accordingly. Use difflib.unified_diff
inside a Markdown diff fence longer than every backtick run in its content.
Normalise line endings for display and disclose that final-newline differences
are ignored. This avoids raw Markdown interpretation and unsafe embedded HTML.

The current export reads the LIVE input with the OLD result at 4153. Capture the
submitted source and situation with accepted results, including history reopen,
and use that snapshot for both existing study-sheet and new diff exports. Update
the selected main translation from _current_main ("Use this" aware), but exclude
finishing touches from the faithful diff. UI text changed since submission must
never silently become the old result's export source.

P1 clipboard correctness: OpenClipboard(None), then EmptyClipboard(), leaves
no owner; Microsoft's SetClipboardData documentation identifies this as a failure
case. The helper also ignores allocation, locking and transfer failures and can
report True after publishing nothing. Pass a real Tk window HWND, check every
allocation and transfer, and free only handles whose ownership did not transfer.
Prepare both memory blocks before emptying the clipboard. Supply CF_UNICODETEXT
and registered "HTML Format" data; HTML is the rich format, not an RTF payload.
Retain the existing UTF-8 byte-offset CF_HTML builder. [S8]

Clipboard contention should cause a visible retry/copy message or the existing
plain-text fallback, not a sleeping loop on the GUI thread. If Windows accepts
one format and rejects the other, an atomic rollback is not promised. The fallback
may replace the partial publication with plain text. HTML escaping at 4172–4174
already avoids treating translated content as markup; retain it.

Metrics already count Python Unicode code points and whitespace-separated
tokens, with 200 English / 180 French words per minute. These are explicit
heuristics, not grapheme counts or measured reading speed. Retain them to avoid
unrequested statistical churn. Add the same label beneath the primary translation
and refresh it for "Use this" and finishing-touch changes. Bind the underlying
Tk Text <<Modified>> event so mouse-paste/undo/programmatic edits are counted;
the same edit revision supports safe asynchronous import. Coalesce updates if
testing shows chatter; the default input size does not justify a metrics worker.

2.5 Backend resilience and streaming preparation
-------------------------------------------------

Current retries already cover HTTP 429/502/503/504 and broad network exceptions.
Keep one shared transport helper; nested retries inside both backend wrappers
would multiply attempts. Improve these concrete gaps:
- Retry-After supports seconds and HTTP-date; the existing numeric-only parser
  clamps even a long server-requested wait to eight seconds. A server minimum
  must not be shortened: if it exceeds the retry-wait budget, stop and ask the
  user to retry later. [S9]
- Jitter must be inside the eight-second exponential cap, not added afterwards.
- Close HTTPError responses before sleeping; never render backend response bodies
  or arbitrary exception.reason text in UI diagnostics.
- Catch IncompleteRead and RemoteDisconnected as transient response failures;
  do not retry malformed JSON, authentication errors or certificate validation.
- Bound attempts and accumulated retry waits; distinguish these from per-socket
  timeouts. urllib's timeout is not a strict whole-request wall-clock deadline.
- Add optional threading.Event cancellation to break waits and stop future
  attempts when Clear/close supersedes work. An already-blocked urllib call may
  continue until its socket timeout; stale request IDs still protect the UI.
- Anthropic documents overload HTTP 529: opt it in only at the Claude call site,
  not as an assumption about every backend. [S10]

Retrying a POST after a lost response can duplicate server work and cost. The
Messages/Ollama flows here have no verified exactly-once guarantee; state this
engineering limitation. Do not invent an idempotency header. The proposed code
keeps network-drop retries requested in the brief, bounded to four attempts.

Streaming preparation only: preserve stream=False now. Future Claude SSE and
Ollama NDJSON need different incremental parsers. Claude can emit an error after
HTTP 200; Ollama's transport is newline-delimited JSON. Buffer UTF-8 correctly,
bound event size and total text, ignore unknown permitted event types, and require
the provider's terminal event. Parse the final assembled translation through the
existing parser and restore placeholders before enabling Copy/Export/History.
Never expose incomplete JSON as a finished translation. [S10–S12]

Suggested internal stream event contract: (request_id, kind, payload), where
kind is progress, complete or error. Only the Tk queue pump touches widgets.
Coalesce progress to at most 10 updates/second and use a bounded queue. After
any partial output, stop on failure and offer Restart; never transparently append
a retry's new generation to the old one. Streaming changes require distinct
provider tests and are deliberately not presented as a ready-to-enable patch.

```python
class WindowsFileDrop:
    """Queue one Explorer file path without entering Tk from WNDPROC."""

    # Retain callbacks even if another subclass prevents safe early removal.
    _pins = []

    def __init__(self, hwnd: int, events):
        if sys.platform != "win32":
            raise OSError("File dropping is available on Windows only.")
        self.hwnd = hwnd
        self.events = events
        self.enabled = True
        self.user32 = ctypes.WinDLL("user32", use_last_error=True)
        self.shell32 = ctypes.WinDLL("shell32", use_last_error=True)
        pointer = ctypes.c_void_p
        signed = ctypes.c_ssize_t
        unsigned = ctypes.c_size_t
        suffix = "PtrW" if ctypes.sizeof(pointer) == 8 else "W"
        self.set_proc = getattr(self.user32, "SetWindowLong" + suffix)
        self.get_proc = getattr(self.user32, "GetWindowLong" + suffix)
        self.set_proc.argtypes = [pointer, ctypes.c_int, signed]
        self.set_proc.restype = signed
        self.get_proc.argtypes = [pointer, ctypes.c_int]
        self.get_proc.restype = signed
        self.forward = self.user32.CallWindowProcW
        self.forward.argtypes = [
            pointer, pointer, ctypes.c_uint, unsigned, signed,
        ]
        self.forward.restype = signed
        self.accept = self.shell32.DragAcceptFiles
        self.accept.argtypes = [pointer, ctypes.c_int]
        self.accept.restype = None
        self.query = self.shell32.DragQueryFileW
        self.query.argtypes = [
            pointer, ctypes.c_uint, ctypes.c_wchar_p, ctypes.c_uint,
        ]
        self.query.restype = ctypes.c_uint
        self.finish = self.shell32.DragFinish
        self.finish.argtypes = [pointer]
        self.finish.restype = None
        prototype = ctypes.WINFUNCTYPE(
            signed, pointer, ctypes.c_uint, unsigned, signed,
        )
        self.callback = prototype(self._window_proc)
        self.address = ctypes.cast(self.callback, pointer).value
        ctypes.set_last_error(0)
        self.previous = self.set_proc(hwnd, -4, self.address)
        error = ctypes.get_last_error()
        if not self.previous and error:
            raise ctypes.WinError(error)
        self._pins.append(self)
        self.accept(hwnd, True)

    def _window_proc(self, hwnd, message, wparam, lparam):
        """Always release HDROP; forward every message we do not own."""
        if message == 0x0233:  # WM_DROPFILES
            try:
                if self.enabled:
                    if self.query(wparam, 0xFFFFFFFF, None, 0) != 1:
                        self.events.put_nowait(("notice", "Drop one file."))
                    else:
                        length = self.query(wparam, 0, None, 0)
                        if not 0 < length <= 32767:
                            raise ValueError("Invalid dropped path.")
                        buffer = ctypes.create_unicode_buffer(length + 1)
                        copied = self.query(wparam, 0, buffer, length + 1)
                        if copied != length:
                            raise ValueError("Incomplete dropped path.")
                        self.events.put_nowait(("path", buffer.value))
            except Exception:
                # No Python exception may escape through a native callback.
                # A full queue means an earlier drop is already being handled.
                pass
            finally:
                self.finish(wparam)
            return 0
        if message == 0x0082:  # WM_NCDESTROY
            self.enabled = False
            self.hwnd = None
        return self.forward(self.previous, hwnd, message, wparam, lparam)

    def close(self):
        """Disable drops and restore only a chain that we still head."""
        self.enabled = False
        if self.hwnd is None:
            return
        self.accept(self.hwnd, False)
        current = ctypes.c_void_p(self.get_proc(self.hwnd, -4)).value
        if current == self.address:
            ctypes.set_last_error(0)
            previous = self.set_proc(self.hwnd, -4, self.previous)
            if not previous and ctypes.get_last_error():
                raise ctypes.WinError(ctypes.get_last_error())
            self.hwnd = None
        # The pinned object survives until process exit, including chain cases.


def find_tk_text(widget):
    """Find the public Tk Text child without using CTk private attributes."""
    if isinstance(widget, tk.Text):
        return widget
    for child in widget.winfo_children():
        found = find_tk_text(child)
```

```python
IMPORT_BYTE_LIMIT = 2 * 1024 * 1024
DOCX_EXPANDED_LIMIT = 8 * 1024 * 1024


def read_import_text(path: str, character_limit: int) -> str:
    """Read a small source document; never truncate or extract ZIP files."""
    extension = os.path.splitext(path)[1].casefold()
    if extension not in {".txt", ".md", ".docx"}:
        raise ValueError("Choose a .txt, .md or .docx file.")
    if not os.path.isfile(path):
        raise ValueError("Choose a file rather than a folder.")
    with open(path, "rb") as source:
        raw = source.read(IMPORT_BYTE_LIMIT + 1)
    if len(raw) > IMPORT_BYTE_LIMIT:
        raise ValueError("The file exceeds the 2 MiB import limit.")
    if extension == ".docx":
        try:
            from docx import Document
            from docx.text.paragraph import Paragraph
        except ImportError as exc:
            raise ValueError(
                "Word import needs the optional python-docx extra."
            ) from exc
        try:
            with zipfile.ZipFile(io.BytesIO(raw)) as archive:
                members = archive.infolist()
                if len(members) > 512 or sum(
                    item.file_size for item in members
                ) > DOCX_EXPANDED_LIMIT:
                    raise ValueError("The Word document is too large.")
                if any(item.flag_bits & 1 for item in members):
                    raise ValueError("Encrypted Word files are not supported.")
            document = Document(io.BytesIO(raw))
            if not hasattr(document, "iter_inner_content"):
                raise ValueError("Word import needs python-docx 1.2 or newer.")
            if document.element.xpath(".//w:ins | .//w:del"):
                raise ValueError("Accept tracked changes before importing.")
            if document.element.xpath(".//w:tbl//w:tbl"):
                raise ValueError("Nested Word tables are not supported.")
            parts = []
            for block in document.iter_inner_content():
                if isinstance(block, Paragraph):
                    parts.append(block.text)
                else:
                    for row in block.rows:
                        cells = (cell.text for cell in row.cells)
                        parts.append("\t".join(cells))
            text = "\n".join(parts)
        except ValueError:
            raise
        except Exception as exc:
            # Parser details can contain paths or document content.
            raise ValueError("The Word document could not be read.") from exc
    else:
        has_utf16_bom = raw.startswith((b"\xff\xfe", b"\xfe\xff"))
        encoding = "utf-16" if has_utf16_bom else "utf-8-sig"
        try:
            text = raw.decode(encoding)
        except UnicodeError as exc:
            raise ValueError(
                "Save the text file as UTF-8, then import it."
            ) from exc
    text = text.replace("\r\n", "\n").replace("\r", "\n")
    if "\x00" in text:
        raise ValueError("The file contains unsupported null characters.")
    valid, message = validate_source_size(text, character_limit)
    if not valid:
        raise ValueError(message)
    return text
```

```python
def _start_file_import_support(self):
    """Initialise file import after Tk has created the native text window."""
    self._import_events = queue.Queue(maxsize=4)
    self._import_results = queue.Queue(maxsize=1)
    self._import_busy = False
    self._import_stopping = False
    self._input_revision = 0
    self._file_drop = None
    self._import_text_widget = find_tk_text(self.input_box)
    if self._import_text_widget is not None:
        self._import_text_widget.edit_modified(False)
        self._import_text_widget.bind(
            "<<Modified>>", self._on_text_modified, add="+",
        )
        if sys.platform == "win32":
            try:
                self._file_drop = WindowsFileDrop(
                    self._import_text_widget.winfo_id(), self._import_events,
                )
            except (OSError, AttributeError):
                self._import_notice(
                    "File dropping is unavailable; use Open file."
                )
    self._import_after = self.after(75, self._poll_file_import)


def _on_text_modified(self, _event=None):
    """Track all edits, including menu paste, undo and programmatic changes."""
    if self._import_text_widget.edit_modified():
        self._input_revision += 1
        self._import_text_widget.edit_modified(False)
        self._on_input_change()


def _import_notice(self, text):
    self.advisory.configure(text=text)
    self.advisory.grid()


def _open_source_file(self):
    """Reuse the same asynchronous reader as Explorer drops."""
    path = filedialog.askopenfilename(
        parent=self, title="Open source text",
        filetypes=[("Source documents", "*.txt *.md *.docx")],
    )
    if path:
        self._begin_file_import(path)


def _begin_file_import(self, path):
    if self._import_stopping:
        return
    if self._import_busy:
        self._import_notice("A file is already being read.")
        return
    self._import_busy = True
    revision = self._input_revision
    request_id = self._request_id
    limit = coerce_positive_int(
        self.config_data.get("max_input_chars"), DEFAULT_MAX_INPUT_CHARS,
    )
    results = self._import_results

    def worker():
        try:
            payload = (True, read_import_text(path, limit))
        except ValueError as exc:
            payload = (False, str(exc))
        except Exception:
            payload = (False, "The file could not be read.")
        results.put((revision, request_id, path, payload))

    threading.Thread(target=worker, daemon=True).start()


def _poll_file_import(self):
    """Deliver work on Tk's thread and reject superseded imports."""
    if self._import_stopping:
        return
    try:
        while True:
            kind, value = self._import_events.get_nowait()
            if kind == "path":
                self._begin_file_import(value)
            else:
                self._import_notice(value)
    except queue.Empty:
        pass
    try:
        revision, request_id, path, payload = self._import_results.get_nowait()
    except queue.Empty:
        pass
    else:
        ok, text = payload
        current = (self._input_revision, self._request_id)
        if current != (revision, request_id):
            self._import_notice(
                "Import discarded because the message changed."
            )
        elif not ok:
            self._import_notice(text)
        else:
            replace = not self._input_text() or messagebox.askyesno(
                "Replace source text",
                "Replace the current source with this file?",
                parent=self,
            )
            # Recheck after the modal question's nested event loop.
            current = (self._input_revision, self._request_id)
            if (
                replace and not self._import_stopping
                and current == (revision, request_id)
            ):
                self._clear()
                self.input_box.insert("1.0", text)
                self._on_input_change()
                if path.casefold().endswith(".docx"):
                    self._import_notice(
                        "Imported body text and tables only. "
                        "Review before translating."
```

```python
def copy_html_to_windows_clipboard(
    html_fragment: str, plain_text: str, hwnd=None,
) -> bool:
    """Transfer prepared memory blocks; free only untransferred handles."""
    if sys.platform != "win32" or not hwnd or "\x00" in plain_text:
        return False
    owned = []
    opened = False
    try:
        user32 = ctypes.WinDLL("user32", use_last_error=True)
        kernel32 = ctypes.WinDLL("kernel32", use_last_error=True)
        pointer = ctypes.c_void_p
        user32.RegisterClipboardFormatW.argtypes = [ctypes.c_wchar_p]
        user32.RegisterClipboardFormatW.restype = ctypes.c_uint
        user32.OpenClipboard.argtypes = [pointer]
        user32.OpenClipboard.restype = ctypes.c_int
        user32.EmptyClipboard.argtypes = []
        user32.EmptyClipboard.restype = ctypes.c_int
        user32.CloseClipboard.argtypes = []
        user32.CloseClipboard.restype = ctypes.c_int
        user32.SetClipboardData.argtypes = [ctypes.c_uint, pointer]
        user32.SetClipboardData.restype = pointer
        kernel32.GlobalAlloc.argtypes = [ctypes.c_uint, ctypes.c_size_t]
        kernel32.GlobalAlloc.restype = pointer
        kernel32.GlobalLock.argtypes = [pointer]
        kernel32.GlobalLock.restype = pointer
        kernel32.GlobalUnlock.argtypes = [pointer]
        kernel32.GlobalUnlock.restype = ctypes.c_int
        kernel32.GlobalFree.argtypes = [pointer]
        kernel32.GlobalFree.restype = pointer
        html_format = user32.RegisterClipboardFormatW("HTML Format")
        if not html_format:
            return False
        plain_text = plain_text.replace("\r\n", "\n").replace("\r", "\n")
        formats = (
            (
                13,
                (plain_text.replace("\n", "\r\n") + "\0").encode("utf-16-le"),
            ),
            (html_format, _build_cf_html(html_fragment) + b"\0"),
        )
        prepared = []
        for format_id, data in formats:
            handle = kernel32.GlobalAlloc(0x0042, len(data))
            if not handle:
                return False
            owned.append(handle)
            address = kernel32.GlobalLock(handle)
            if not address:
                return False
            try:
                ctypes.memmove(address, data, len(data))
            finally:
                kernel32.GlobalUnlock(handle)
            prepared.append((format_id, handle))
        if not user32.OpenClipboard(hwnd):
            return False
        opened = True
        if not user32.EmptyClipboard():
            return False
        for format_id, handle in prepared:
            if not user32.SetClipboardData(format_id, handle):
                return False
            owned.remove(handle)
        return True
    except Exception:
        return False
    finally:
        if opened:
            user32.CloseClipboard()
        for handle in owned:
            kernel32.GlobalFree(handle)
```

```python
def _backoff_delay(attempt, retry_after=None) -> float:
    """Honour a valid server minimum; otherwise use capped equal jitter."""
    if isinstance(retry_after, str):
        value = retry_after.strip()
        if re.fullmatch(r"[0-9]{1,9}", value):
            return float(value)
        try:
            instant = parsedate_to_datetime(value)
            if instant.tzinfo is None:
                instant = instant.replace(tzinfo=timezone.utc)
            return max(0.0, instant.timestamp() - time.time())
        except (TypeError, ValueError, OverflowError):
            pass
    ceiling = min(HTTP_BACKOFF_CAP, HTTP_BACKOFF_BASE * 2 ** attempt)
    return secrets.SystemRandom().uniform(ceiling / 2.0, ceiling)


def _http_post_json(
    url, payload, headers, timeout, service_name="backend",
    max_attempts=HTTP_MAX_ATTEMPTS, *, cancel_event=None,
    retryable_codes=None, max_retry_wait=30.0,
):
    """Retry transient failures without exposing sensitive content."""
    attempts = min(HTTP_MAX_ATTEMPTS, max(1, int(max_attempts or 1)))
    codes = (
        HTTP_RETRYABLE_CODES if retryable_codes is None else retryable_codes
    )
    encoded = json.dumps(payload).encode("utf-8")
    waited = 0.0
    network_message = (
        "Could not reach the translation backend. "
        "Check your connection and retry."
    )
    transient_errors = (
        TimeoutError, ConnectionError, socket.gaierror,
        http.client.IncompleteRead, http.client.RemoteDisconnected,
    )

    def check_cancelled():
        if cancel_event is not None and cancel_event.is_set():
            raise BackendError("The request was cancelled.")

    for attempt in range(attempts):
        check_cancelled()
        retry_after = None
        failure = network_message
        request = urllib.request.Request(
            url, data=encoded, headers=headers, method="POST",
        )
        try:
            with urllib.request.urlopen(request, timeout=timeout) as response:
                raw = response.read(2 * 1024 * 1024 + 1)
            if len(raw) > 2 * 1024 * 1024:
                raise BackendError("The backend response was too large.")
            check_cancelled()
            try:
                return json.loads(raw.decode("utf-8"))
            except (UnicodeError, ValueError) as exc:
                raise BackendError(
                    "The backend response could not be read."
                ) from exc
        except urllib.error.HTTPError as exc:
            code = exc.code
            retry_after = (
                exc.headers.get("Retry-After") if exc.headers else None
            )
            exc.close()
            failure = _friendly_http_message(code, service_name)
            if code not in codes:
                raise BackendError(failure) from None
        except urllib.error.URLError as exc:
            if isinstance(exc.reason, ssl.SSLError):
                raise BackendError(
                    "The secure connection could not be verified."
                ) from None
            if not isinstance(exc.reason, transient_errors):
                raise BackendError(network_message) from None
        except ssl.SSLError:
            raise BackendError(
                "The secure connection could not be verified."
            ) from None
        except transient_errors:
            pass
        except OSError:
            # Unknown local/socket failures are not assumed to be transient.
            raise BackendError(network_message) from None
        if attempt + 1 == attempts:
            raise BackendError(failure)
        delay = _backoff_delay(attempt, retry_after)
        if delay > max_retry_wait - waited:
            raise BackendError(
                "The backend needs a longer pause. Please retry later."
            )
        if cancel_event is None:
            time.sleep(delay)
        elif cancel_event.wait(delay):
            raise BackendError("The request was cancelled.")
        waited += delay
    raise BackendError(network_message)
```

Focused acceptance tests for implementation:
- Native drop: accents, emoji paths, spaces, long paths, uppercase suffix,
  multiple files, directories, repeated drops, hide/show tray, exit with a pending
  drop, repeated startup/shutdown, 100/150/200% scaling and the packaged build.
- Import: UTF-8/BOM/UTF-16, invalid bytes, null bytes, exact/over-limit text,
  missing Word extra, corrupt/encrypted/oversized ZIP, body/table ordering,
  tracked changes refusal, edit/Clear/request during read, replacement cancelled.
- Presets: absent tones, malformed tone entries, duplicate names/IDs, cap,
  ConfigError/OSError save failure leaves memory unchanged, Settings snapshot
  cannot revert newer presets, optional profile round-trip and dispatch guard.
- Tones: enumerate catalogue sequences of length 0–4; test malformed list/dict
  members, idempotence, membership, uniqueness, cap and every conflict edge.
  Click each conflicting choice in each of the three slots to confirm recency.
- Exports: embedded backticks/HTML, accents, blank lines, equal inputs, adopted
  alternative, edited live input and reopened history all retain provenance.
- Clipboard: allocation/lock/transfer failure frees only caller-owned handles;
  contention leaves existing clipboard alone before EmptyClipboard; paste into
  Notepad and an HTML-aware target; validate CF_HTML UTF-8 offsets with emoji.
- Retry: 429/503 then success, terminal 401/403/404, HTTP-date and long
  Retry-After, bounded jitter/waits, closed HTTPError, IncompleteRead, certificate
  error with no retry, malformed JSON with no retry, cancellation before and
  during wait, no response-body leakage, Claude 529 versus Ollama policy.

Changing retry/tone contracts deliberately changes some current test expectations.
In particular, the old numeric Retry-After cap test must become a server-minimum
test plus wait-budget refusal. Do not alter tests merely to make failures vanish;
assert the documented new behaviour. Existing tests do not exercise live native
clipboard ownership or WNDPROC subclassing; a green headless suite is insufficient
evidence to ship those native features.
