1. Executive summary
------------------------------------------------------------------------
Plume is in good health. The live module is still a single, well-
sectioned file: sections 1–5 stay import-safe and headless-testable;
GUI work is confined to sections 6–7. Privacy guarantees hold (no
source text in status, errors or titles; Claude/ElevenLabs gated by
acknowledgement; local history opt-in). Background work still has a
stale-callback guard for both translation and TTS. v1.9–v1.14 closed
the live-conversation loop without adding a second purpose.

Two daily-use gaps remain, and they are the highest-value next steps:

  1. English that is about to be sent as French is often drafted
     quickly, with typos. The model currently translates the typos
     faithfully, which is correct under the existing contract and
     wrong for the user. A dedicated Correct English pass, using the
     same urllib Anthropic/Ollama path as translate(), should overwrite
     the source box with cleaned British English and then proceed to
     English → French. Correction is not rewriting: spelling, grammar
     and necessary punctuation only.

  2. Plume is a conversation companion. Starting it by hand every
     session, then hunting for the window, fights that role. Windows 11
     sign-in autostart (HKCU Run, via winreg) plus a feature-gated
     system-tray icon (pystray + Pillow) lets it sit quietly and come
     forward on click. Close-to-tray replaces today's WM_DELETE_WINDOW
     destroy path when the extra is installed.

Five architectural follow-ons keep the app a translator, not a word
processor:

  * Native WM_DROPFILES onto input_box, no TkDND.
  * User-defined conversation presets in plume_config.json.
  * Up to three stacked register tones with conflict resolution, wired
    as background context the way Situation already is — source meaning
    still wins; no embellishment.
  * Current-result Markdown export, HTML clipboard, and a reading-time
    metric beside the existing character count. Favourites export
    already exists (v1.13); this is for the working result.
  * Exponential backoff with jitter in _http_post_json for 429/502/503/
    504 and dropped connections, plus a small extraction seam so a
    later streaming slice does not rewrite the backends.

========================================================================
FEATURE A — Correct English, then translate to French   [v1.15]
========================================================================
UX rationale
------------
The user drafts in English, then wants French. Typos in the English
become faithful French mistakes. The fix is a second, narrower model
call — not a silent rewrite inside translate() — so the user always
sees the English that was actually translated.

Behaviour
---------
1. A "Correct English" button sits to the left of Translate on the
   existing left-pane button row (Paste / Clear / Copy source / Reply
   | Correct English / Translate).
2. Enabled when the direction is English → French, or Auto-detect and
   looks_like_english() is true. Disabled for French → English, with
   the existing advisory strip explaining why.
3. Click: same in-flight lock as Translate (Correct, Translate, Reply
   and Use as input all disable). Status becomes "correcting English…".
4. Worker: protect_text (including keep_as_is_terms) → correction
   prompt via run_backend() → parse_correction_result() → restore
   tokens. One JSON object, not free prose.
5. Delivery, if not stale: overwrite input_box with corrected_text,
   refresh the character count, then immediately start the existing
   _translate() path. Direction is forced to English → French for that
   translation only when Auto-detect was selected and the source was
   treated as English; a user who had already pinned English → French
   is left pinned. Situation is untouched.
6. If the user edited the box while correction was in flight, do not
   overwrite and do not auto-translate (same "generated for an earlier
   message" discipline as _deliver).
7. If the model reports changes_made = false, still overwrite with the
   normalised text (whitespace tidy only) and continue, so the pipeline
   is one click either way.
8. Keyboard: Ctrl+Shift+Enter on the input box. Ctrl+Enter remains
   Translate only, so a user who trusts their English is not taxed.

Why a separate prompt, not a translate() preamble
-------------------------------------------------
translate()'s contract is one primary + five alternatives in the
*other* language. Folding correction into that JSON would either
silently mutate the source (the user never sees what was translated)
or bloat the schema. Two calls, one overwrite, then the existing
pipeline, keeps every validator and the history source_text honest:
history records the corrected English, which is what was sent.

State / config
--------------
DEFAULT_CONFIG gains nothing required. Optional, off by default, for
people who want Translate itself to correct first:

    "correct_english_before_translate": false

When true, _translate() runs the correction pass automatically if the
source looks English. The dedicated button still exists and always
corrects-then-translates, matching the requested workflow. Recommend
shipping the button first and leaving the flag false until the prompt
has been lived with — auto-correcting French pasted under Auto-detect
would be a real foot-gun.

Privacy: correction uses the same backend as translation, so the
existing Claude privacy acknowledgement covers it. No new notice.
Ollama remains the local option.

Performance: one extra round-trip only when the button (or the opt-in
flag) is used. ANTHROPIC_MAX_TOKENS can stay 4096; conversational
messages are short. Correction max_tokens of 1024 is enough if we pass
it through a new optional argument later; not required for v1.15.

Prompt invariants (anti-rewrite)
--------------------------------
* British English spelling (organise, colour, defence, practise as
  the verb).
* Fix spelling, grammar, and punctuation required for correctness.
* Do not paraphrase, change register, add or remove clauses, translate,
  "improve" the wording, or insert facts.
* Preserve names, placeholders, emoji, line breaks and the user's
  hedging / slang / ellipses.
* If the text is already correct, return it unchanged with
  changes_made = false.

FEATURE B — Start with Windows 11, minimised to the tray   [v1.16]
========================================================================
UX rationale
------------
A conversation helper that has to be launched and parked every session
gets closed. Sign-in autostart plus a tray icon matches Always on top
(v1.9): Plume is present without occupying the desktop.

Feature gate
------------
Tray icon, close-to-tray and start-minimised require pystray and
Pillow. If either import fails, Plume runs exactly as today; the three
tray checkboxes in Settings are disabled with a one-line caption.
Sign-in autostart uses winreg only and does *not* depend on pystray —
but the Run-key command always passes --start-minimised, so a machine
without the extras would flash a window at logon. Therefore: enabling
"Launch when I sign in" while tray extras are missing is refused with
that caption, rather than writing a Run key that pops a window.

Config (all default false)
--------------------------
    "launch_at_sign_in": false
    "start_minimised_to_tray": false
    "close_to_tray": false

Behaviour
---------
* launch_at_sign_in: HKCU\Software\Microsoft\Windows\CurrentVersion\Run
  value name "Plume". Command is quoted:
    frozen:  "{sys.executable}" --start-minimised
    source:  "{sys.executable}" "{abspath(plume.py)}" --start-minimised
  Never point the Run key at Plume.bat (it can pause on error).
* start_minimised_to_tray: after the window is constructed, withdraw()
  and start the tray icon. Also honoured when --start-minimised is on
  argv (the autostart path).
* close_to_tray: WM_DELETE_WINDOW hides to the tray instead of
  destroy(). Tray menu: Show, Quit. Quit is the only path that
  invalidates in-flight work and destroys, matching today's _on_close.
  Left-click the icon also shows the window (Windows 11 habit).
* Show restores geometry, deiconify(), lift(), focus. Always-on-top is
  re-applied so a hidden-then-shown window does not lose v1.9's flag.
* Single instance is deliberately out of scope. A second launch just
  opens a second window; a mutex would be a new failure mode for a
  first tray slice.

PyInstaller: if the extras are installed at freeze time, add
hiddenimports ["pystray", "PIL"]. If they are not, the frozen app
behaves as today. Do not make them hard requirements in
requirements.txt; add a commented optional block instead.

The tray thread must marshal every UI action through self.after(0, …).
pystray's callback thread is not the Tk thread.

FEATURE C — Explorer drag-and-drop                         [v1.18]
========================================================================
Native WM_DROPFILES via ctypes (shell32.DragAcceptFiles + a WndProc
subclass). No tkdnd, no windnd. Drops on the top-level HWND land in
input_box (the brief's original_box).

Accepted extensions: .txt, .md always (UTF-8, BOM stripped). .docx
only when python-docx imports; otherwise a friendly advisory, no
crash. Over-long files hit validate_source_size and are refused.
Multiple files: first supported file wins; extras ignored with one
advisory. Drop replaces the current source (it is "here is a message
to translate", not a merge). Keep-as-is / placeholders are not applied
until Translate/Correct, matching Paste.

Subclass after update_idletasks() so the HWND exists. Unsubclass in
_on_close / Quit so a late drop cannot run against a destroyed Tk.
Keep a Python reference to the ctypes callback or it will be
collected and crash the process.

FEATURE D — User conversation presets                      [v1.19]
========================================================================
SITUATION_PRESETS (v1.11) stay as local-only quick-fills for the
Situation field. User presets are a different object: a named snapshot
of the live conversation controls.

Schema, stored in plume_config.json as "conversation_presets" (list,
cap 12). Not a second file.

    {
      "id": "<uuid hex>",
      "name": "Work email",
      "direction": "English → French",
      "french_formality": "Formal (vous)",
      "speaker_gender": "Feminine",
      "recipient_gender": "Feminine",
      "situation": "formal work email",
      "tones": ["precise", "courteous"]
    }

normalise_conversation_preset() drops unknown ids/fields, coerces
enums with the existing _coerce_choice helpers, caps the name at 40
characters, and caps tones via validate_tones() (Feature E). A
malformed list becomes [] rather than crashing load_config.

UI: an OptionMenu "Presets…" on toolbar row 1 (after You), plus "Save
preset…" which prompts for a name and snapshots the current controls.
Choosing a preset writes direction / form / Me / You / situation /
tones and calls _on_toolbar_change. It does not persist until Settings
is saved, matching today's toolbar-wins-at-save rule — except the
preset *list* itself is saved immediately on Save preset / Delete, so
a named preset cannot vanish on a crash.

FEATURE E — Three-tone register combinator                 [v1.20]
========================================================================
Plume is not a writing rewriter. "Tones" here are register hints for
the translator, the same class of information as Situation, and they
must never outrank the source.

Catalogue (closed; British labels):

    TONE_NONE = "None"
    REGISTER_TONES = (
        TONE_NONE, "Warm", "Terse", "Playful", "Precise",
        "Courteous", "Direct", "Reassuring",
    )

Conflicts (later selection wins, earlier conflicting tone dropped):

    frozenset({"Terse", "Playful"})
    frozenset({"Terse", "Warm"})
    frozenset({"Playful", "Precise"})
    frozenset({"Direct", "Reassuring"})

validate_tones(seq) → at most 3 unique real tones, order preserved,
conflicts resolved, unknowns dropped, "None" ignored.

build_tone_instruction(tones) → a short clause injected next to the
existing situation_clause in build_translation_prompt, with the same
anti-instruction / anti-embellishment guard: background register only;
do not add facts, jokes, soften or intensify commitments, or change
JSON shape. Source text wins on conflict.

UI: three compact OptionMenus under the Situation row, default None.
Choosing a conflicting third tone silently drops the conflicting
earlier one and refreshes the menus — no modal.

build_user_envelope gains an optional tones line, omitted when empty,
so existing callers and tests stay green.

FEATURE F — Current-result export, HTML clipboard, metrics [v1.21]
========================================================================
v1.13 already exports *favourites*. This slice is the working result.

* "Export" on the primary card writes a Markdown file via filedialog
  (source, situation, main, five alternatives with meaning checks, and
  a fenced unified diff of source vs main using difflib.unified_diff —
  useful as a study view, not as a claim that the two are the same
  language). Reuse _export_field discipline: no leaked keys.
* "Copy as HTML" puts a small HTML fragment on the Windows clipboard
  (CF_HTML via ctypes) and plain text as fallback via the existing
  Tk clipboard. Non-Windows: plain text only.
* char_label becomes "N characters · M words · ~Xs to read" using
  text_metrics(). English ~200 wpm, French ~180 wpm; Auto-detect uses
  200. Never include the source wording.

FEATURE G — Backend resilience and streaming preparation   [v1.17]
========================================================================
_http_post_json currently fails on the first 429/503 or dropped
socket. Translation already runs on a worker thread, so a short sleep
there is safe.

* Retry 429, 502, 503, 504, URLError (non-HTTP), TimeoutError, OSError.
* Do not retry 401, 403, 404, or 400.
* Up to 4 attempts (1 + 3 retries). Exponential backoff 0.6 s · 2^n,
  capped at 8 s, plus secrets.SystemRandom jitter (0–25 %). Honour
  Retry-After when it is a numeric delay, still capped at 8 s.
* HTTPError must be caught before URLError (it is a subclass).
* After exhaustion, keep the existing friendly messages. Never echo
  body text.

Streaming preparation (no streaming in this slice):

* Lift Anthropic text extraction into _anthropic_text_from_response().
* Lift Ollama content extraction into _ollama_text_from_response().
* Set "stream": False explicitly on the Anthropic payload so a later
  SSE slice is a one-key change. Do not implement SSE or token
  painting in CustomTkinter yet — that is a v2 concern and would
  change the JSON-only contract.

call_elevenlabs_tts is out of scope for retry in v1.17 (it is a
different helper). A one-line follow-up can wrap it the same way.

File: plume.py — section 4, after parse_translation_result (after

    _CORRECTION_SCHEMA = """{
      "corrected_text": "the corrected English, or the original if already correct",
      "changes_made": true or false,
      "notes": ["optional short notes"]
    }"""


    def looks_like_english(text: str) -> bool:
        """Cheap, conservative guard. Diacritics => treat as not-English.

        Used only to enable the Correct English button under Auto-detect.
        A forced English → French direction always wins over this helper.
        Accented loanwords in English (café) may be refused; that is
        preferable to running an English corrector over a French SMS.
        """
        if not isinstance(text, str) or not text.strip():
            return False
        if re.search(r"[àâçéèêëîïôùûüÿœæÀÂÇÉÈÊËÎÏÔÙÛÜŸŒÆ]", text):
            return False
        return True


    def build_correction_prompt() -> str:
        """System prompt for English spelling and grammar correction only."""
        return (
            "You are a precise copy-editor for British English. The user will "
            "send a short conversational message that is about to be translated "
            "into French.\n"
            "Correct spelling, grammar and only the punctuation required for "
            "correctness. Use British English spelling (organise, colour, "
            "defence, practise as a verb, licence as a noun).\n"
            "Do not paraphrase. Do not change register, tone, hedging, slang, "
            "ellipsis or emoji. Do not add or remove clauses, facts or "
            "courtesy. Do not translate. Do not 'improve' the wording. "
            "Preserve names, placeholder tokens of the form "
            "\u27e6PH0\u27e7, line breaks, and any quoted content exactly.\n"
            "If the text is already correct, return it unchanged and set "
            "changes_made to false.\n\n"
            "Return only one valid JSON object matching this shape, with no "
            "Markdown fences and no prose before or after it:\n"
            + _CORRECTION_SCHEMA
        )


    def parse_correction_result(raw) -> dict:
        """Validate a correction response. Never returns submitted text in errors."""
        if not isinstance(raw, str) or not raw.strip():
            raise TranslationValidationError("The model returned an empty response.")
        text = _strip_code_fence(raw)
        try:
            data = json.loads(text)
        except ValueError:
            raise TranslationValidationError(
                "The model did not return valid JSON. Please try again."
            )
        if not isinstance(data, dict):
            raise TranslationValidationError(
                "The model response was not a single JSON object."
            )
        corrected = data.get("corrected_text")
        if not isinstance(corrected, str) or not corrected.strip():
            raise TranslationValidationError(
                "The response had no usable corrected text."
            )
        return {
            "corrected_text": corrected.replace("\r\n", "\n"),
            "changes_made": bool(data.get("changes_made")),
            "notes": _safe_string_list(data.get("notes", [])),
        }


    def correct_english(config_snapshot, text: str) -> dict:
        """Mask, correct, restore. Same worker-thread shape as translate()."""
        protect = bool(config_snapshot.get("protect_placeholders", True))
        masked, mapping = protect_text(
            text,
            enabled=protect,
            extra_terms=normalise_keep_as_is_terms(
                config_snapshot.get("keep_as_is_terms")
            ),
        )
        raw = run_backend(
            config_snapshot,
            build_correction_prompt(),
            "English text to correct:\n{}".format(masked),
        )
        result = parse_correction_result(raw)
        restored = restore_tokens(result["corrected_text"], mapping)
        if mapping and any(token in restored for token in mapping):
            result["notes"] = [
                "One or more protected items may not have been reproduced "
                "exactly. Please check the corrected English before sending it."
            ] + result.get("notes", [])
        result["corrected_text"] = restored
        return result

    class WindowsDropTarget:
        """Accept Explorer file drops on a Tk top-level via WM_DROPFILES."""

        def __init__(self, widget, on_files):
            self.widget = widget
            self.on_files = on_files
            self._old_proc = None
            self._callback = None
            self._hwnd = None

        def attach(self):
            if sys.platform != "win32":
                return
            self.widget.update_idletasks()
            user32 = ctypes.windll.user32
            shell32 = ctypes.windll.shell32
            hwnd = user32.GetAncestor(self.widget.winfo_id(), 2)  # GA_ROOT
            if not hwnd:
                hwnd = self.widget.winfo_id()
            self._hwnd = hwnd
            shell32.DragAcceptFiles(hwnd, True)
            if ctypes.sizeof(ctypes.c_void_p) == 8:
                LRESULT = ctypes.c_longlong
                GetWindowLong = user32.GetWindowLongPtrW
                SetWindowLong = user32.SetWindowLongPtrW
            else:
                LRESULT = ctypes.c_long
                GetWindowLong = user32.GetWindowLongW
                SetWindowLong = user32.SetWindowLongW
            WNDPROC = ctypes.WINFUNCTYPE(
                LRESULT, ctypes.c_void_p, ctypes.c_uint,
                ctypes.c_void_p, ctypes.c_void_p,
            )
            self._old_proc = GetWindowLong(hwnd, GWLP_WNDPROC)

            def _proc(h, msg, wparam, lparam):
                if msg == WM_DROPFILES:
                    try:
                        self._handle_drop(wparam)
                    except Exception:
                        pass
                    return 0
                return ctypes.windll.user32.CallWindowProcW(
                    self._old_proc, h, msg, wparam, lparam
                )

            self._callback = WNDPROC(_proc)  # keep referenced
            SetWindowLong(hwnd, GWLP_WNDPROC, self._callback)

        def detach(self):
            if sys.platform != "win32" or not self._hwnd or not self._old_proc:
                return
            user32 = ctypes.windll.user32
            setter = (user32.SetWindowLongPtrW
                      if ctypes.sizeof(ctypes.c_void_p) == 8
                      else user32.SetWindowLongW)
            try:
                setter(self._hwnd, GWLP_WNDPROC, self._old_proc)
                ctypes.windll.shell32.DragAcceptFiles(self._hwnd, False)
            except Exception:
                pass
            self._hwnd = None

        def _handle_drop(self, hdrop):
            shell32 = ctypes.windll.shell32
            count = shell32.DragQueryFileW(hdrop, 0xFFFFFFFF, None, 0)
            paths = []
            for index in range(count):
                size = shell32.DragQueryFileW(hdrop, index, None, 0) + 1
                buf = ctypes.create_unicode_buffer(size)
                shell32.DragQueryFileW(hdrop, index, buf, size)
                paths.append(buf.value)
            shell32.DragFinish(hdrop)
            self.widget.after(0, lambda: self.on_files(paths))

    def _backoff_delay(attempt, retry_after=None) -> float:
        """Seconds to wait before the next attempt. *attempt* is 0-based."""
        if retry_after not in (None, ""):
            try:
                header_delay = float(retry_after)
                if header_delay >= 0:
                    return min(header_delay, HTTP_BACKOFF_CAP)
            except (TypeError, ValueError):
                pass
        delay = min(HTTP_BACKOFF_CAP, HTTP_BACKOFF_BASE * (2 ** attempt))
        jitter = secrets.SystemRandom().uniform(0.0, delay * 0.25)
        return delay + jitter


    def _http_post_json(url, payload, headers, timeout, service_name="backend",
                        max_attempts=HTTP_MAX_ATTEMPTS):
        """POST JSON with bounded exponential backoff for transient failures."""
        data = json.dumps(payload).encode("utf-8")
        last_network_message = None
        attempts = max(1, int(max_attempts or 1))
        for attempt in range(attempts):
            request = urllib.request.Request(
                url, data=data, headers=headers, method="POST"
            )
            try:
                with urllib.request.urlopen(request, timeout=timeout) as response:
                    body = response.read().decode("utf-8")
                break
            except urllib.error.HTTPError as exc:
                retry_after = None
                try:
                    retry_after = exc.headers.get("Retry-After")
                except Exception:
                    retry_after = None
                if exc.code in HTTP_RETRYABLE_CODES and attempt < attempts - 1:
                    time.sleep(_backoff_delay(attempt, retry_after))
                    continue
                raise BackendError(_friendly_http_message(exc.code, service_name))
            except urllib.error.URLError as exc:
                last_network_message = (
                    "Could not reach the translation backend. Please check your "
                    "connection and try again. ({})".format(_reason_text(exc))
                )
                if attempt < attempts - 1:
                    time.sleep(_backoff_delay(attempt))
                    continue
                raise BackendError(last_network_message)
            except (TimeoutError, OSError):
                last_network_message = (
                    "The translation backend did not respond in time. "
                    "Please try again."
                )
                if attempt < attempts - 1:
                    time.sleep(_backoff_delay(attempt))
                    continue
                raise BackendError(last_network_message)
        else:
            raise BackendError(
                last_network_message
                or "The translation backend did not respond in time. Please try again."
            )
        try:
            return json.loads(body)
        except ValueError:
            raise BackendError(
                "The backend returned a response that could not be read."
            )


    def _anthropic_text_from_response(data) -> str:
        """Pull concatenated text blocks from a Claude Messages body."""
        if not isinstance(data, dict):
            raise BackendError(
                "The Claude API returned a response that could not be read."
            )
        if data.get("stop_reason") == "max_tokens":
            raise BackendError(
                "The translation was cut short by the model's length limit. "
                "Please shorten the message and try again."
            )
        parts = []
        for block in data.get("content", []):
            if isinstance(block, dict) and block.get("type") == "text":
                parts.append(block.get("text", ""))
        text = "".join(parts).strip()
        if not text:
            raise BackendError("The Claude API returned an empty message.")
        return text


    def _ollama_text_from_response(data) -> str:
        if not isinstance(data, dict):
            raise BackendError("Ollama returned a response that could not be read.")
        if data.get("error"):
            raise BackendError(
                "Ollama reported an error. Please check the model name in Settings."
            )
        message = data.get("message") or {}
        text = (message.get("content") or "").strip()
        if not text:
            raise BackendError("Ollama returned an empty message.")
        return text

5. Sequencing, risks, and what not to do
------------------------------------------------------------------------
Land v1.15 and v1.16 first — they are the two requested behaviours.
v1.17 (backoff) is a small, no-UI win and can ride with either.

Risks worth naming before implementation:

* Correction is a second paid Claude call. Keep it behind an explicit
  button; do not default correct_english_before_translate to true.
* looks_like_english() will refuse "café at 6". Accept that. A false
  refusal is recoverable (user hits Translate); a false accept would
  English-correct a French SMS.
* WndProc subclassing is the most fragile slice. If WM_DROPFILES
  misbehaves on a particular CustomTkinter build, fail closed:
  DragAcceptFiles off, no crash, Paste still works.
* pystray's icon.run() is blocking; it must stay on a daemon thread,
  and every callback must hop to Tk via after(0, …).
* Always-on-top + start-minimised: withdraw first, then the tray Show
  path re-applies -topmost. Do not set topmost on a withdrawn window
  as the only show mechanism — some Windows 11 builds then restore
  behind other windows.
* Do not introduce scriptorium_config.json, a writing-mode selector,
  or a silent rewrite of English inside translate(). Those would give
  Plume a second purpose.

Out of scope, still:

* Speech input, live voice agent, cloud sync, extra language pairs,
  regional French presets pending native-speaker review.

When implementation is authorised, work in that order (v1.15 → v1.16
→ v1.17, then C–F), keep the test run green, and wait for an explicit
push instruction per AGENTS.md.
