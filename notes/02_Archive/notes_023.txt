------------------------------------------------------------------------
1. Executive summary
------------------------------------------------------------------------
Plume is no longer missing a translator, a glossary, a phrasebook, or a
tray notice. The remaining friction is *between* bursts: the window is
buried under a game, "Oui, vers 19h" is translated with no memory of
the cinema turn that Reply just finished, Add-to-glossary still saves
only one direction, and Clear is still irreversible.

Recommended order (v1.50–v1.53):

  A. Isolated restore hotkey, gated on a throwaway HWND harness.
     notes_022 2.E designed this and v1.49 explicitly deferred it.
     Message-only HWND on its own thread, or it does not ship.
     APP_VERSION is bumped in the same commit.  (v1.50)
  B. Reply-thread previous exchange. Reply already means "my turn is
     over"; it should also remember that turn as background context
     for the next translation, so ellipsis and "vers 19h" resolve.
     One pair, in memory, never persisted, never a chat agent.  (v1.51)
  C. Glossary reverse pair + glossary fidelity. The leftover from
     notes_022 2.B, plus extending v1.48's lint so "Auridon" without
     "Auridia" (or "d'Auridia") is visible.  (v1.52)
  D. Undo last Clear. One in-memory snapshot. Clear now also drops
     the live phrasebook and the v1.51 thread pair; recovering from
     a mis-click should not cost a backend call.  (v1.53)

UX rationale: a gaming/conversation helper is used in short bursts
beside Explorer, Discord and a game. Alt-Tab hunting for Plume, a
context-free "oui", a second glossary Add for the reverse pair, and
an accidental Clear are the four gestures that still feel heavier
than they should. None of this changes the JSON contract, the
two-pane layout, or the "source text wins" prompt rule.

2. Detailed architectural proposals

2.0  Housekeeping: APP_VERSION drift
------------------------------------
ROADMAP v1.46 required `APP_VERSION` to be bumped alongside each later
version so a rebuilt .exe is identifiable in the title bar. The
constant at plume.py:104 is still `"1.46"` after v1.47–v1.49 landed.
This is not its own version. The next commit that touches plume.py
sets `APP_VERSION` to the version being shipped (1.50 if 2.A lands;
1.49 if 2.A is dropped after a failed harness). Do not leave it
stale a second time.

2.A  Isolated restore hotkey  (v1.50)
-------------------------------------
notes_022 2.E stands. Restated here only where the live tree has
moved on (window show path is now `_show_window` at 6227, close path
is `_on_close_destroy` at 6174, tray menu already has "Show Plume"
and "Show and paste clipboard").

Do **not** subclass the Tk toplevel WndProc. v1.18 crashed the
interpreter on a foreign WM_DROPFILES; WM_HOTKEY on the same
procedure is the same class of risk.

Design, non-negotiable:

  * A dedicated message-only HWND (`HWND_MESSAGE = -3`) created on a
    daemon thread that owns the window and pumps `GetMessageW`.
  * That thread's WndProc understands only `WM_HOTKEY` (0x0312) and
    `WM_DESTROY`. Everything else is `DefWindowProcW`.
  * On WM_HOTKEY the procedure sets a `threading.Event`; it never
    calls into Tk.
  * The Tk thread polls the event with `after(200, ...)` and, when
    set, calls the existing `_show_window()` (deiconify, lift,
    focus, honour always-on-top). Never auto-translates. Never
    pastes. "Show and paste clipboard" stays a tray-menu action.
  * Default chord: Ctrl+Shift+P (`MOD_CONTROL | MOD_SHIFT |
    MOD_NOREPEAT`, vk `'P'`). MOD_NOREPEAT so a held chord does not
    queue fifty restores.
  * Settings checkbox `restore_hotkey`, off by default, independent
    of the tray extras — a user who never enables close-to-tray
    still wants the window back from a game. Placed with the tray
    checkboxes (around 3568) so the two "how Plume is summoned"
    controls sit together, with a caption naming the chord.
  * `RegisterHotKey` failure (chord taken by another app): leave the
    checkbox off, one-line Settings status, no crash, no retry loop.
  * Teardown in `_on_close_destroy`: PostMessage a quit to the
    message-only HWND, UnregisterHotKey, DestroyWindow, join the
    thread with a short timeout. Never leak the HWND across a
    Settings toggle: turning the checkbox off takes the same path.

Hard gate: a throwaway harness, not Plume, must survive one
externally triggered WM_HOTKEY on Mark's machine before this version
is committed. The harness is a 40-line ctypes script with no Tk, no
CustomTkinter, no Plume imports. If it crashes, hangs, or fails to
unregister, drop v1.50 rather than attaching anything to Tk. The
tray menu already restores the window.

New config key, coerced on load:

  "restore_hotkey": false

Performance: one extra daemon thread that blocks in GetMessageW,
plus a 200 ms Tk poll that is a single Event.is_set(). Idle cost is
noise next to the existing tray thread.

2.B  Reply-thread previous exchange  (v1.51)
--------------------------------------------
Today `_reply` (5991) copies the working main, swaps direction, and
clears the input. Situation is left untouched on purpose (v1.9): it
is a persistent scene descriptor, not a per-turn note. The cost is
that the next pasted reply — "Oui, vers 19h" — is translated with
no record of "Tu veux aller au ciné ce soir ?". Users can type that
into Situation, and in practice they do not.

This is not a chat agent and not a rolling history dump. It is one
remembered pair, installed by the gesture the user already makes
when a turn ends.

State on PlumeApp, in-memory only:

  self._previous_exchange = None
  # or {"source": str, "translation": str}

Rules:

  * Reply, if a working main exists, writes the pair from
    `_result_source_text` and `_current_main`, each passed through
    `_safe_short_string(..., PREVIOUS_EXCHANGE_MAX_CHARS)` with
    PREVIOUS_EXCHANGE_MAX_CHARS = 240 (the existing note cap).
  * Clear sets it to None. Undo Clear (2.D) restores the snapshot's
    copy. Closing the app forgets it. It is never written to
    plume_config.json or plume_history.json.
  * The next `translate()` includes it when the snapshot carries
    `_previous_exchange`. Re-translate of the same incoming paste
    keeps it (Reply is not consumed by success). The next Reply
    overwrites it with the new pair.
  * "Use as input" and "Correct English" do not set it. Use-as-input
    is a different loop (the translation becomes the new source) and
    must not silently attach the old source as context.
  * Phrasebook entries are still never sent.

Prompt contract, mirroring Situation/tones/glossary:

  * A system-prompt clause, omitted entirely when no pair is set.
  * An envelope pair of lines, omitted when empty, so existing
    callers and tests that omit the argument keep today's shape.
  * Background only. Must not change JSON shape, add/remove fields,
    override direction, or outrank the current source. If the
    previous turn conflicts with what this source says, this source
    wins. Do not invent facts the current source does not support
    merely because they appeared last turn.
  * Not masked with protect_text. Situation is not masked either;
    this is background, not "text to translate". `_safe_short_string`
    is the bound.

UI:

  * No new toolbar checkbox. Reply is the opt-in gesture.
  * A one-line grey caption under the Paste/Clear/Copy source/Reply
    row, always visible: "Reply remembers this turn for the next
    translation. Clear ends the thread."
  * When a pair is set, a short `self.thread_label` on that same
    row reads "Thread on" (never echoing source text). Hidden when
    None.

No DEFAULT_CONFIG key. Nothing to coerce on load.

Performance: two 240-character strings on the snapshot and in the
prompt. Negligible against a 2,000-character source and the existing
glossary clause.

2.C  Glossary reverse pair + glossary fidelity  (v1.52)
-------------------------------------------------------
notes_022 2.B specified a checkbox "Also save the reverse pair"
(Auridon=Auridia and Auridia=Auridon), default on when both sides
look like a single proper name. v1.47 shipped Add-from-result
without it, so a gaming term still needs two Adds. notes_021's
Auridon example is exactly this pair.

Also, v1.48's `fidelity_notes` checks Keep-as-is terms and ignores
the glossary. A preferred rendering that the model dropped is
silent, including the grammatical form `d'Auridia`.

Reverse pair:

  * New helper `looks_like_proper_name(text) -> bool`:
    `looks_like_single_term(text, GLOSSARY_MAX_TERM_CHARS)` and the
    trimmed value is one token (no spaces) or one hyphenated /
    apostrophe token (`Marie-Claire`, `O'Neill`). Letters, hyphen
    and apostrophe only. Rejects "guardians of Auridon".
  * New helper `reverse_glossary_entry(entry) -> dict | None`:
    swaps term/translation and runs the result through
    `normalise_glossary_entries`. None if it cannot be salvaged or
    if both sides casefold-equal (a no-op reverse).
  * GlossaryDialog: a `CTkCheckBox` "Also save the reverse pair"
    under the Add row (row 2, push the existing caption down).
    Default on when both fields pass `looks_like_proper_name`, off
    while editing an existing row (an edit that silently wrote a
    second entry would surprise). `_add_main_to_glossary` does not
    need to set it; opening the dialog with both fields filled will
    tick it via the same KeyRelease preview path.
  * `_add_or_update` (4755): after a successful forward persist, if
    the checkbox is on, not editing, and `len(entries) <
    GLOSSARY_MAX_ENTRIES`, append the reverse if its source is not
    already present (casefold). If the glossary is full at 19, save
    the forward pair and notice "Reverse pair skipped (glossary
    full)." Never delete an existing reverse to make room.
  * Duplicate reverse source: skip with a notice, keep the forward
    pair. First-wins stays the glossary rule.

Glossary fidelity, folded into `fidelity_notes` rather than a second
advisory pass (one cap at MAX_NOTES):

  * New optional argument `glossary=()`.
  * For each pair, if the source contains the term as a
    token (`keep_as_is_pattern(term)` casefolded — reuse the
    existing token-boundary idea, compiled case-insensitive) and
    the preferred rendering's casefolded form is absent from the
    haystack *after* stripping French elision prefixes
    (`d'`, `l'`, `n'`, `m'`, `t'`, `s'`, `j'`, `c'`, `qu'`), append
    one tentative line: "Glossary term \"Auridon\" does not appear
    as \"Auridia\" in the translations."
  * This is the same "does not appear" voice as v1.48. Never "is
    wrong". Never claims the elision was required.
  * Cap still MAX_NOTES. Keep-as-is lines stay first (they are
    stronger promises: the term was supposed to be copied verbatim).
  * `_deliver` (7014) passes
    `glossary=self.config_data.get("translation_glossary") or []`.

Do not add a direction field. notes_021 declined it; two one-line
pairs remain the shape.

Performance: one extra checkbox, one extra normalise call on Add,
and a handful of casefold scans over ≤ 2,000 characters.

2.D  Undo last Clear  (v1.53)
-----------------------------
`_clear` (6148) is now more destructive than in v1.43: it drops the
input, the result, the live phrasebook, and (once 2.B lands) the
thread pair. There is no recovery short of Reopen from History, and
History is off by default.

One in-memory snapshot, taken immediately before Clear mutates
anything. Not persisted. Not sent to either backend.

Snapshot keys (a plain dict on `self._clear_snapshot`):

  input, situation, direction,
  current_result, current_main, result_source_text, result_situation,
  phrasebook_entries (a *copy* of the list of dicts),
  previous_exchange (a copy or None)

Rules:

  * One level. A second Clear replaces the snapshot.
  * Empty Clear (already-blank input, no result, empty phrasebook,
    no thread) still snapshots, so Undo is a true revert rather than
    a guess at "was there anything".
  * Restore: write the fields back, slice-assign the phrasebook
    (never rebind — v1.43 Clear bug), refresh an open
    PhrasebookDialog, `_render_result` if current_result is not
    None else `_clear_results`, `_on_input_change`. Do not bump
    `_request_id` (no in-flight work is involved).
  * Do not restore finishing-touch / sign-off / MMORPG pickers;
    Clear resetting those is still correct.
  * Do not restore an in-flight Translate; Clear still supersedes
    pending work, and Undo does not resurrect a cancelled request.

UI:

  * `Undo Clear` button on the translate row (5202), left side next
    to Open file…, width ~90, grey, disabled until a snapshot
    exists. The Paste/Clear/Copy source/Reply row is already at its
    four-button budget at 1000×600 (v1.15 moved Translate off it
    for exactly this reason); do not add a fifth button there.
  * Ctrl+Shift+Z bound on the toplevel. Not Ctrl+Z — that belongs
    to the text box's own undo. The handler is a no-op while the
    button is disabled.
  * After a successful undo, disable the button (the snapshot is
    spent). Clearing again re-enables it.

No config key.

Performance: one extra dict holding strings the UI already held.
Taken only on Clear.

# Constants, near AUTOSTART_RUN_KEY (line 110).

RESTORE_HOTKEY_VK = 0x50          # 'P'
RESTORE_HOTKEY_MODS = 0x0002 | 0x0004 | 0x4000  # CONTROL|SHIFT|NOREPEAT
RESTORE_HOTKEY_ID = 1
_WM_HOTKEY = 0x0312
_WM_DESTROY = 0x0002
_HWND_MESSAGE = -3
_HOTKEY_CLASS = "PlumeRestoreHotkey"


def _restore_hotkey_available() -> bool:
    """True only on Windows with a working user32/kernel32 ctypes bind."""
    if sys.platform != "win32":
        return False
    try:
        ctypes.windll.user32
        ctypes.windll.kernel32
    except Exception:
        return False
    return True


class RestoreHotkey:
    """Message-only HWND on its own thread. Never talks to Tk.

    The Tk thread is expected to poll `self.fired` and call
    PlumeApp._show_window itself. Construction does not register
    the hotkey; call start() from Settings/__init__ once the
    checkbox is on.
    """

    def __init__(self):
        self.fired = threading.Event()
        self._thread = None
        self._hwnd = 0
        self._ready = threading.Event()
        self._error = ""

    def start(self) -> str:
        """Register the chord. Returns an error string, or \"\"."""
        if self._thread is not None and self._thread.is_alive():
            return ""
        if not _restore_hotkey_available():
            return "Restore hotkey is only available on Windows."
        self._ready.clear()
        self._error = ""
        self._thread = threading.Thread(target=self._run, daemon=True)
        self._thread.start()
        self._ready.wait(3.0)
        return self._error

    def stop(self) -> None:
        hwnd = self._hwnd
        if hwnd:
            try:
                ctypes.windll.user32.PostMessageW(hwnd, _WM_DESTROY, 0, 0)
            except Exception:
                pass
        thread = self._thread
        if thread is not None:
            thread.join(1.0)
        self._thread = None
        self._hwnd = 0

    def _run(self) -> None:
        user32 = ctypes.windll.user32
        kernel32 = ctypes.windll.kernel32

        WNDPROC = ctypes.WINFUNCTYPE(
            ctypes.c_long, ctypes.c_void_p, ctypes.c_uint,
            ctypes.c_void_p, ctypes.c_void_p,
        )

        def wndproc(hwnd, msg, wparam, lparam):
            if msg == _WM_HOTKEY and int(wparam) == RESTORE_HOTKEY_ID:
                self.fired.set()
                return 0
            if msg == _WM_DESTROY:
                try:
                    user32.UnregisterHotKey(hwnd, RESTORE_HOTKEY_ID)
                except Exception:
                    pass
                user32.PostQuitMessage(0)
                return 0
            return user32.DefWindowProcW(hwnd, msg, wparam, lparam)

        self._wndproc_ref = WNDPROC(wndproc)  # keep alive for the pump

        class WNDCLASS(ctypes.Structure):
            _fields_ = [
                ("style", ctypes.c_uint),
                ("lpfnWndProc", WNDPROC),
                ("cbClsExtra", ctypes.c_int),
                ("cbWndExtra", ctypes.c_int),
                ("hInstance", ctypes.c_void_p),
                ("hIcon", ctypes.c_void_p),
                ("hCursor", ctypes.c_void_p),
                ("hbrBackground", ctypes.c_void_p),
                ("lpszMenuName", ctypes.c_wchar_p),
                ("lpszClassName", ctypes.c_wchar_p),
            ]

        wc = WNDCLASS()
        wc.lpfnWndProc = self._wndproc_ref
        wc.hInstance = kernel32.GetModuleHandleW(None)
        wc.lpszClassName = _HOTKEY_CLASS
        if not user32.RegisterClassW(ctypes.byref(wc)):
            # Already registered from a previous start in this process
            # is acceptable; a genuine failure is not.
            err = kernel32.GetLastError()
            if err not in (1410,):  # ERROR_CLASS_ALREADY_EXISTS
                self._error = "Could not register the restore-hotkey window class."
                self._ready.set()
                return

        hwnd = user32.CreateWindowExW(
            0, _HOTKEY_CLASS, "Plume hotkey", 0,
            0, 0, 0, 0, _HWND_MESSAGE, None, wc.hInstance, None,
        )
        if not hwnd:
            self._error = "Could not create the restore-hotkey window."
            self._ready.set()
            return
        self._hwnd = hwnd
        if not user32.RegisterHotKey(
            hwnd, RESTORE_HOTKEY_ID, RESTORE_HOTKEY_MODS, RESTORE_HOTKEY_VK
        ):
            self._error = (
                "Ctrl+Shift+P is already in use by another application."
            )
            user32.DestroyWindow(hwnd)
            self._hwnd = 0
            self._ready.set()
            return
        self._ready.set()

        msg = ctypes.create_unicode_buffer(48)  # MSG is 48 bytes on Win64
        # Peek/GetMessage with a real MSG struct:
        class MSG(ctypes.Structure):
            _fields_ = [
                ("hwnd", ctypes.c_void_p),
                ("message", ctypes.c_uint),
                ("wParam", ctypes.c_void_p),
                ("lParam", ctypes.c_void_p),
                ("time", ctypes.c_uint),
                ("pt_x", ctypes.c_long),
                ("pt_y", ctypes.c_long),
            ]
        message = MSG()
        while user32.GetMessageW(ctypes.byref(message), 0, 0, 0) != 0:
            user32.TranslateMessage(ctypes.byref(message))
            user32.DispatchMessageW(ctypes.byref(message))

PREVIOUS_EXCHANGE_MAX_CHARS = 240


def normalise_previous_exchange(value) -> dict | None:
    """Return a clean {source, translation} pair, or None.

    In-memory only — never persisted. A missing or oversized field
    drops the whole pair rather than sending a half-remembered turn.
    """
    if not isinstance(value, dict):
        return None
    source = _safe_short_string(value.get("source"), PREVIOUS_EXCHANGE_MAX_CHARS)
    translation = _safe_short_string(
        value.get("translation"), PREVIOUS_EXCHANGE_MAX_CHARS
    )
    if not source or not translation:
        return None
    return {"source": source, "translation": translation}


def build_previous_exchange_instruction(value) -> str:
    """Background-only last-turn clause, or \"\" when none is set."""
    pair = normalise_previous_exchange(value)
    if pair is None:
        return ""
    return (
        "\n\nPrevious exchange (background only): the user's last turn "
        "was:\nPrevious source: " + pair["source"] + "\n"
        "Previous translation: " + pair["translation"] + "\n"
        "Use it solely to resolve pronouns, ellipsis, short replies "
        "and time/place references in the current source. It must not "
        "change the required JSON output shape, add or remove fields, "
        "override the requested direction, or add facts, offers or "
        "commitments the current source does not make. If it conflicts "
        "with what the current source text itself conveys, the current "
        "source wins."
    )

_PROPER_NAME = re.compile(r"^[A-Za-zÀ-ÖØ-öø-ÿ]+(?:[-'][A-Za-zÀ-ÖØ-öø-ÿ]+)*$")
_ELISION_PREFIXES = ("d'", "l'", "n'", "m'", "t'", "s'", "j'", "c'", "qu'")


def looks_like_proper_name(text: str) -> bool:
    """True when *text* is one name-shaped token, not a phrase."""
    if not looks_like_single_term(text, GLOSSARY_MAX_TERM_CHARS):
        return False
    value = (text or "").strip()
    if " " in value:
        return False
    return bool(_PROPER_NAME.match(value))


def reverse_glossary_entry(entry) -> dict | None:
    """Swap term/translation. None if it cannot be salvaged."""
    if not isinstance(entry, dict):
        return None
    swapped = normalise_glossary_entries([{
        "term": entry.get("translation"),
        "translation": entry.get("term"),
    }])
    if not swapped:
        return None
    reverse = swapped[0]
    if reverse["term"].casefold() == reverse["translation"].casefold():
        return None
    return reverse


def _haystack_without_elision(text: str) -> str:
    folded = (text or "").casefold()
    for prefix in _ELISION_PREFIXES:
        folded = folded.replace(prefix, "")
    return folded


def glossary_fidelity_notes(source, haystack, glossary) -> list:
    """Tentative advisories when a preferred rendering is absent."""
    source = source or ""
    folded_haystack = _haystack_without_elision(haystack)
    notes = []
    for entry in normalise_glossary_entries(glossary):
        term = entry["term"]
        preferred = entry["translation"]
        if not re.search(
            r"(?<!\w)" + re.escape(term) + r"(?!\w)", source, re.IGNORECASE
        ):
            continue
        token = preferred.casefold()
        if token and token not in folded_haystack:
            notes.append(
                "Glossary term \"{}\" does not appear as \"{}\" in the "
                "translations.".format(term, preferred)
            )
            if len(notes) >= MAX_NOTES:
                break
    return notes

# PlumeApp.__init__:

        def _take_clear_snapshot(self) -> dict:
            """Capture the fields Clear is about to drop. In-memory only."""
            previous = None
            pair = getattr(self, "_previous_exchange", None)
            if pair:
                previous = dict(pair)
            return {
                "input": self._input_text(),
                "situation": self._situation_text(),
                "direction": self.direction_var.get(),
                "current_result": self._current_result,
                "current_main": self._current_main,
                "result_source_text": self._result_source_text,
                "result_situation": self._result_situation,
                "phrasebook_entries": [
                    dict(item) for item in self._phrasebook_entries
                ],
                "previous_exchange": previous,
            }

        def _clear(self):
            self._clear_snapshot = self._take_clear_snapshot()
            self._request_id += 1
            self._speech_request_id += 1
            self._new_http_cancel()
            self.translate_btn.configure(state="normal", text="Translate")
            self.correct_btn.configure(state="normal", text="Correct English")
            self.reply_btn.configure(state="normal")
            self.input_box.delete("1.0", "end")
            self._clear_results()
            self._phrasebook_entries.clear()
            if self._phrasebook_dialog is not None and self._phrasebook_dialog.winfo_exists():
                self._phrasebook_dialog._refresh_list()
                self._phrasebook_dialog._note_cleared()
            self._previous_exchange = None
            self._on_input_change()
            self._refresh_status(state="ready")
            self._set_undo_clear_enabled(True)

        def _undo_clear(self):
            snap = self._clear_snapshot
            if not snap:
                return
            self.direction_var.set(snap["direction"])
            self.input_box.delete("1.0", "end")
            self.input_box.insert("1.0", snap["input"])
            self.situation_entry.delete(0, "end")
            self.situation_entry.insert(0, snap["situation"])
            self._phrasebook_entries[:] = [
                dict(item) for item in snap["phrasebook_entries"]
            ]
            if self._phrasebook_dialog is not None and self._phrasebook_dialog.winfo_exists():
                self._phrasebook_dialog._refresh_list()
            self._previous_exchange = (
                dict(snap["previous_exchange"])
                if snap["previous_exchange"]
                else None
            )
            self._result_source_text = snap["result_source_text"]
            self._result_situation = snap["result_situation"]
            self._current_main = snap["current_main"]
            self._current_result = snap["current_result"]
            if snap["current_result"]:
                self._render_result(snap["current_result"])
            else:
                self._clear_results()
            self._clear_snapshot = None
            self._set_undo_clear_enabled(False)
            self._on_input_change()
            self._refresh_status(state="ready")

        def _set_undo_clear_enabled(self, enabled: bool) -> None:
            state = "normal" if enabled else "disabled"
            try:
                self.undo_clear_btn.configure(state=state)
            except tk.TclError:
                pass

        def _undo_clear_shortcut(self, event):
            if str(self.undo_clear_btn.cget("state")) == "normal":
                self._undo_clear()
            return "break"
